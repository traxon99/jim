Static mockups for the social redesign, not app code. `mockup-source.html` renders each screen with
`?s=1..6` (add `&dark` for dark mode); it expects `roboto.css` and `icons.js` beside it, so open the
PNGs instead.

2. Workout post, exercises slide with PRP calls, reaction picker open
3. Record post and People you may know
4. Comments sheet
